# Memory index — my-Oracle

ดัชนีความทรงจำถาวรของ Oracle สำหรับ repo นี้

## โครงสร้าง

| โฟลเดอร์ | ใช้เก็บ |
|----------|---------|
| `user/` | ความชอบ ภาษา เวลาทำงาน ข้อจำกัดของผู้ใช้ |
| `feedback/` | สิ่งที่ควรทำต่อ/ไม่ควรทำ จากการทำงานร่วมกัน |
| `project/` | สถาปัตยกรรม การตัดสินใจ งานค้างของโปรเจกต์ |
| `reference/` | ลิงก์ เอกสาร มาตรฐานภายนอก |
